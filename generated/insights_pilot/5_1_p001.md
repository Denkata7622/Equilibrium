Теория\n### 3.1 Интуиция — пример преди формула\nНека разгледаме конкретна задача: \"Квадратното уравнение x² - 5x + 6 = 0 има корени 2 и 3. Намери сумата и произведението им.\" Лесно: 2+3=5, 2*3=6. Забележи, че 5 е противоположното на коефициента пред x, а 6 е свободният член. Сега да пробваме с друго: x² + 7x + 12 = 0 с корени -3 и -4. Сума: -3 + (-4) = -7 (противоположно на коефициента пред x). Произведение: (-3)*(-4)=12 (свободен член). Виждаш ли вече модела?\n\n### 3.2 Формално определение\nЗа общо квадратно уравнение ax² + bx + c = 0 с корени x₁ и x₂:\n- **Сума на корените**: x₁ + x₂ = -b/a\n- **Произведение на корените**: x₁x₂ = c/a\n\nЗа кубично уравнение ax³ + bx² + cx + d = 0 с корени x₁, x₂, x₃:\n- x₁ + x₂ + x₃ = -b/a\n- x₁x₂ + x₂x₃ + x₃x₁ = c/a\n- x₁x₂x₃ = -d/a\n\nЗа уравнение от n-та степен: aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀ = 0 с корени x₁, x₂, ..., xₙ:\n- Сума на всички корени: ∑xᵢ = -aₙ₋₁/aₙ\n- Сума на произведенията по два: ∑xᵢxⱼ = aₙ₋₂/aₙ\n- ...\n- Произведение на всички корени: ∏xᵢ = (-1)ⁿ a₀/aₙ\n\n### 3.3 Теореми с доказателства\n**Теорема 1 (квадратно уравнение)**: Ако x₁, x₂ са корени на ax² + bx + c = 0, то x₁ + x₂ = -b/a и x₁x₂ = c/a.\n*Доказателство*: Разлагаме на множители: a(x - x₁)(x - x₂) = 0. Разкриваме скобите: a[x² - (x₁+x₂)x + x₁x₂] = ax² - a(x₁+x₂)x + a x₁x₂. Сравняваме с оригиналното уравнение ax² + bx + c = 0. Коефициентите трябва да съвпадат:\n- При x: -a(x₁+x₂) = b ⇒ x₁+x₂ = -b/a\n- Свободен член: a x₁x₂ = c ⇒ x₁x₂ = c/a. ∎\n\n**Теорема 2 (кубично уравнение)**: Ако x₁, x₂, x₃ са корени на ax³ + bx² + cx + d = 0, то x₁+x₂+x₃ = -b/a, x₁x₂ + x₂x₃ + x₃x₁ = c/a, x₁x₂x₃ = -d/a.\n*Доказателство*: a(x - x₁)(x - x₂)(x - x₃) = 0. Разкриваме скобите стъпка по стъпка:\n1. (x - x₁)(x - x₂) = x² - (x₁+x₂)x + x₁x₂\n2. Умножаваме по (x - x₃): [x² - (x₁+x₂)x + x₁x₂](x - x₃) = x³ - x₃x² - (x₁+x₂)x² + (x₁+x₂)x₃x + x₁x₂x - x₁x₂x₃\nГрупираме: x³ - (x₁+x₂+x₃)x² + (x₁x₂ + x₁x₃ + x₂x₃)x - x₁x₂x₃\nУмножаваме по a: ax³ - a(x₁+x₂+x₃)x² + a(x₁x₂ + x₁x₃ + x₂x₃)x - a x₁x₂x₃\nСравняваме с ax³ + bx² + cx + d:\n- При x²: -a(x₁+x₂+x₃) = b ⇒ x₁+x₂+x₃ = -b/a\n- При x: a(x₁x₂ + x₁x₃ + x₂x₃) = c ⇒ x₁x₂ + x₁x₃ + x₂x₃ = c/a\n- Свободен член: -a x₁x₂x₃ = d ⇒ x₁x₂x₃ = -d/a. ∎\n\n### 3.4 Връзка с училищната математика\nВ училище се учиш, че за квадратно уравнение ax² + bx + c = 0, дискриминантата D = b² - 4ac определя реалността на корените. Но формулите на Виет дават повече — те показват връзката между корените без дори да ги намираш. Например, ако знаеш, че сумата на корените е отрицателна, а произведението положително, то и двата корена са отрицателни (ако са реални). Това не можеш да получиш от дискриминантата.\n\n### 3.5 Множество гледни точки\nМожеш да мислиш за Виет алгебрично или геометрично:\n- **Алгебрично**: Формулите са резултат от разкриване на скоби в разлагането на множители. Фокусът е върху коефициентите.\n- **Геометрично**: За квадратно уравнение, корените са точки, където параболата пресича абсцисната ос. Сумата x₁+x₂ е абсцисата на върха с обратен знак, умножена по 2 (защото върхът е при x = -b/(2a) = (x₁+x₂)/2).\n\n### 3.6 Edge cases\n- **Когато a=0**: Уравнението вече не е квадратно. Формулите не важат! Винаги проверявай степента.\n- **Когато D=0**: Имаме двоен корен x₁ = x₂ = -b/(2a). Сумата е 2*(-b/(2a)) = -b/a, произведение (b²/(4a²)) = c/a. Работи, но е специален случай.\n- **Когато корените са комплексни**: Формулите важат (напр. за x² + 1 = 0: корени i и -i, сума 0 = -0/1, произведение -1 = 1/1? Грешка! Внимавай: x² + 0x + 1 = 0 ⇒ сума = -0/1 = 0, произведение = 1/1 = 1, а i*(-i) = -i² = -(-1) = 1. Да, работи.\n- **Когато коефициентът е нула**: Напр. в x³ - 6x² + 0x + 8 = 0.
